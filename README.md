# ЭТИКТЕКИ

Требования к товарной этикетке для импорта из Китая и продажи на маркетплейсах РФ (Ozon, WB, Яндекс Маркет).

## Состав

- `Требования к этикетке — импорт из Китая для маркетплейсов РФ.md` — основной документ: обязательные данные (ст. 10 ЗоЗПП, ГОСТ Р 51121-97), что можно убрать, макет минимальной этикетки для взрослого велоседла, спорные вопросы, риски и санкции, требования маркетплейсов.
- `figures/etiketka_minimal.png` — визуальный макет минимальной этикетки 58×40 мм (схема, для термопринтера использовать PDF-макеты из рабочего контура).

## Источник

Выгрузка чата «Требования к этикетке» (Kimi, 19.10.2026). Первый разобранный товар — взрослое велосипедное седло МТ08 (EP-00024770).
